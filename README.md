# Gerenciador de Tarefas

Este é um projeto moderno de gerenciamento de tarefas desenvolvido em **React**

---

## Funcionalidades

- **Criar Tarefas**: Adicione novos itens à lista.
- **Marcar como Concluída**: Ative a caixinha (checkbox) para concluir tarefas
- **Filtros Avançados**: Visualize as tarefas divididas entre **Todas**, **Pendentes** ou **Concluídas**
- **Remover Tarefas**: Exclua itens da lista
- **Persistência de Dados**: Suas tarefas não somem se você atualizar a página (F5)

---

## Tecnologias Utilizadas

- **React** (Biblioteca Javascript para a interface)
- **Vite** (Ambiente de desenvolvimento rápido)
- **Hooks Customizados** (Para separar a lógica do visual)
- **API REST (CrudCrud)** (Para salvar e persistir as tarefas na nuvem)
- **Flexbox CSS** (Para alinhar e organizar o layout)

---

## Como rodar o projeto

1. Baixe ou clone este repositório no seu computador
2. Abra a pasta do projeto no seu terminal
3. Instale as dependências rodando o comando:
   ```bash
   npm install
   ```
4. Inicie o servidor de testes com o comando:
   ```bash
   npm run dev
   ```
5. Abra o link gerado (geralmente `http://localhost:5173`) no seu navegador
