# Gerenciador de Produtos

Esse é um projeto simples em **React** para cadastrar e listar produtos de uma loja. Ele salva os dados na internet usando uma API pública do CrudCrud.

## 🚀 Funcionalidades

* 📝 **Cadastro de Produtos:** Formulário para adicionar nome, preço, descrição e imagem.
* 📋 **Listagem Automática:** Mostra todos os produtos cadastrados em cartões visuais.
* 🌐 **Integração com API:** Os dados ficam salvos de verdade usando a API do CrudCrud.

## 🛠️ Tecnologias Utilizadas

* **React.js** (useState e useEffect)
* **HTML5 / CSS** (Styled-components inline com Flexbox)
* **Fetch API** (Para conectar com o servidor)

Abra [http://localhost:3000](http://localhost:3000) no seu navegador para ver o resultado :))

💡 *A URL da API do CrudCrud expira em alguns dias. Se os produtos pararem de carregar, basta criar uma nova chave no site deles e atualizar a variável `API_URL` no código.*
